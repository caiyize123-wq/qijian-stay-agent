# 栖间 · 酒店体验智能体

从酒店里的一个体验开始，把空闲时间变成可以调整的安排。

栖间面向高品质酒店住客：通过飞猪查酒店和体验资料，由阿里云百炼结合同行人、兴趣及时间主动推荐、生成安排，再由程序检查时段、已确定事项和消费约束。主入口是推荐与操作界面，搜索和对话作为补充。

![栖间首页](media/home-desktop.png)

[下载可复现包与实际操作演示](https://github.com/caiyize123-wq/qijian-stay-agent/releases/tag/v0.1.0)

## 可以做什么

- 搜索新酒店，自动取得有来源依据的体验；资料不足时保留基础页与重试。
- 主动推荐、分类浏览、查看原文、收藏与酒店周边查询。
- 生成安排、保留时段、单项替换/移除、参与准备、保存恢复及导出。
- 七尚与安达仕深度样例；其他酒店复用同一处理链路和界面。
- 手机适配；不同酒店的资料及浏览器入住状态隔离。

## 运行

Node.js 24以上；应用无需安装 npm 运行依赖。需要自备百炼与飞猪凭据，以及官方 FlyAI CLI。

```sh
cp .env.example .env.local
# 在本机编辑器填写凭据，然后执行：
npm run check
npm test
npm start
```

打开 `http://127.0.0.1:4381/`。完整说明见 [REPRODUCE.md](REPRODUCE.md)。没有密钥时只能浏览深度样例，不会伪造AI成功。

## 产品边界

这是酒店体验发现与时间安排 MVP，独立于酒店官方服务。平台查询不代表完整、实时或酒店已确认；时间表不是预约。地图为空间示意，新酒店没有内部路网时不提供导航。当前主要验证单次空闲时间，尚未完成多日跨夜、实时活动库存或酒店系统接入。

## 核验与素材

实际百炼与飞猪调用、空库复现、截图、演示及资料核对见 `evidence/` 与 `media/`。测试数据、模拟故障、平台资料、官网核对与真人反馈分别标识。真人试用只能由真实体验者填写，自动化结果不能代替住客反馈。

项目没有默认转授第三方图片或服务的权利；酒店图片、名称及平台数据各归原权利方，出处见 `THIRD_PARTY_NOTICES.md`。本交付包用于参赛评审和复现，尚未指定开源许可证。

## 独立运行检查

`node scripts/smoke-release.mjs` 可在空数据库下检查启动、规则安排与保存。它不调用模型，不计为百炼成功证据。`ci-templates/verify.yml` 是可选云端检查模板；当前仓库授权不允许创建自动工作流，因此尚未运行云端检查。
